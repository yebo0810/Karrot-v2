# AI 협업 기록 — 초안

## 프롬프트 1: 디자인 반론
“상품 상태를 목록에서 강조하려는 내 설계에 반대하는 관점에서, 화면 복잡성·사용자 오해·모바일 사용성을 기준으로 반론하고 개선안을 제시해 줘.”

## 프롬프트 2: 범위 검토
“교수님의 과제 범위(Flutter UI, json-server GET, 로딩/오류/빈 상태, 적응형 레이아웃)를 기준으로 Karrot-v2 기능 중 실제 서버 쓰기, 로그인, 결제, 실제 AI/API 호출을 요구하는 항목이 있는지 검토해 줘.”

※ 제출 전 실제 AI 대화 내용과 본인의 반론·수정 과정을 기록하고, 화면 전후 비교 자료를 추가해야 한다. 이 파일은 기록 형식의 초안이다.
