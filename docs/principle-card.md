# 원칙 카드 (Nielsen 휴리스틱)
- P01 시스템 상태의 가시성: 판매 중/예약 중/경매 예시 상태와 로딩 상태를 표시한다.
- P02 시스템과 현실 세계의 일치: 상품명, 가격, 위치 등 익숙한 표현을 사용한다.
- P03 사용자 제어와 자유: 모달을 닫을 수 있고, AI 문구는 제안으로만 표시한다.
- P04 일관성과 표준: 화면 전반에 동일한 색상과 카드 스타일을 사용한다.
- P05 오류 예방: 거래 상태를 확인하라는 안내를 제공한다.
- P06 인식보다 회상 감소: 검색창과 카테고리 칩을 제공한다.
- P07 유연성과 효율성: 검색 및 카테고리 필터로 항목을 좁힌다.
- P08 미니멀 디자인: 상품 카드에 핵심 정보만 표시한다.
- P09 오류 인식·진단·복구: 서버 오류 시 재시도 버튼을 제공한다.
- P10 도움말과 문서화: 실제 기능이 아닌 예시 UI임을 명시한다.
