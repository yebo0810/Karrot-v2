# Karrot-v2 디자인 가이드

## 목적
대학생이 학교 주변의 중고 상품을 확인하고, 구매 희망 글과 모의 경매 UI를 살펴볼 수 있는 UI 프로토타입.

## 화면 흐름
- A 목록: 중고거래 / 구해요 / 경매 탭, 검색, 태그 필터, 로딩·오류·빈 상태
- B 상세: 상품 이미지, 가격, 위치, 상태, 설명
- C 하단 모달: AI 상품 설명 제안 / 구해요 정보 / 경매 예시

## 화면 요소와 원칙
| 번호 | Flutter 위젯 | 비즈니스 명칭 | 원칙 |
|---|---|---|---|
| A-1 | AppBar | 앱 이름과 알림 진입점 | P04 일관성 |
| A-2 | TextField | 상품 검색 | P06 인식보다 회상 감소 |
| A-3 | ChoiceChip | 카테고리 필터 | P07 효율성 |
| A-4 | ListView / GridView | 상품 카드 목록 | P08 미니멀 디자인 |
| A-5 | FutureBuilder + LoadingView | 불러오는 중 | P01 상태 가시성 |
| A-6 | ErrorView + FilledButton | 오류 및 다시 시도 | P09 오류 복구 |
| A-7 | EmptyView | 결과 없음 | P01 상태 가시성 |
| B-1 | AppBar | 상세 화면 제목/뒤로 가기 | P03 사용자 제어 |
| B-2 | Text + Chip | 상품명, 가격, 상태, 태그 | P02 현실 세계와 일치 |
| B-3 | Container | 거래 상태 안내 | P01 상태 가시성 |
| B-4 | FilledButton | 예시 정보 열기 | P07 효율성 |
| C-1 | showModalBottomSheet | 설명/경매 예시 | P03 사용자 제어 |

## 정보 전달 기준
상품명, 가격, 거래 상태, 위치는 상세 화면에서 눈에 띄게 표시한다. 경매와 AI 설명은 미리 정한 예시이며 실제 계산·AI 호출·입찰은 없다.

## 상태관리 포인트 (설계 기록)
- 현재 구현: 검색어, 카테고리, 선택 탭은 StatefulWidget의 setState로 화면만 갱신.
- 확장 설계: 로그인 상태, 즐겨찾기, 게시글 작성 상태는 실제 구현하지 않음(과제 범위 밖).
