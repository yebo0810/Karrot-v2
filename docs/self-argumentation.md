# 셀프 논증 기록 초안

## 쟁점 1: 상품 상태를 목록에서 눈에 띄게 보여 줄 것인가?
- 내 주장: 상태 정보는 구매자가 거래 가능 여부를 빠르게 판단하는 데 필요하다.
- 반론(AI/반대 관점): 카드에 정보가 많으면 복잡해져 상품 사진과 가격에 집중하기 어렵다.
- 재검토: 목록 카드에는 가격·상품명·위치 중심으로 두고, 상세 화면에서 상태를 별도 강조한다.
- 결론: 유지. 목록은 간결하게, 상세에서는 상태를 명확히 표시한다.
- 근거: P01 시스템 상태 가시성, P08 미니멀 디자인. 리뷰 사례: 예약 상품 때문에 거래가 어려웠다는 사용자 의견.

## 쟁점 2: AI 상품 설명 기능을 실제로 구현할 것인가?
- 내 주장: AI 설명 작성은 게시글 작성을 돕는다.
- 반론(AI/반대 관점): 외부 API와 실제 생성 로직은 과제 범위를 벗어날 수 있다.
- 재검토: 실제 AI 호출 대신 미리 정한 편집 가능한 예시 문구를 모달로 보여 준다.
- 결론: UI만 구현. 실제 생성 기능은 범위 밖으로 둔다.
- 근거: P03 사용자 제어와 자유, P10 안내의 명확성.
